# 📊 Data Dashboards

A collection of interactive data visualization dashboards built as part of my data analytics learning journey. Each project takes a raw dataset and turns it into a clear, decision-ready dashboard covering KPIs, trends, and drill-down insights.

---

## 📌 Overview

This repository brings together several dashboarding projects across different business domains — e-commerce, human resources, and retail sales. Each folder is a self-contained project with its own dataset, dashboard file, and supporting assets.

---

## 🗂️ Projects

### 🛒 Ecommerce Analysis
A dashboard exploring e-commerce performance — sales, orders, products, and customer behavior — to surface revenue trends and top-performing segments.

### 👥 HR Analytics
An HR-focused dashboard analyzing workforce metrics such as headcount, attrition, demographics, and other people-analytics indicators to support HR decision-making.

### 🛍️ Market Sales Analysis
A retail/market sales dashboard tracking sales performance across products, categories, and time periods to highlight patterns and growth opportunities.

## 🚀 How to Use

1. Browse into any project folder above.
2. Open the dashboard file in the relevant BI tool (e.g., Power BI Desktop for `.pbix` files).
3. Interact with the visuals — filter, drill down, and explore the insights.
